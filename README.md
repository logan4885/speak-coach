# 口语教练 Speak Coach（手机版 · Gemini）

说一句英语 → Gemini 听录音并分析 → 纠错报告（原句 / 正确 / 更地道 / 知识点）→ 遮住答案让你再说一遍，检查是否真的掌握。

## 五个核心能力
| 功能 | 在哪 |
|---|---|
| 词汇替换 | 纠错报告里的「词汇」知识点 |
| 语法纠错 | 纠错报告里的「语法」知识点 |
| 地道表达 | 报告里的「更地道」+ 🔊 朗读 |
| 个人错误档案 | 「错误档案」页：错误分类、反复犯的错、AI 弱点诊断。同类错误会归到同一个标签下累计次数 |
| 主动复习 | 「复习」页：按 1/3/7/15/30 天间隔，只给中文意思让你说英语 |

## 怎么装到手机上
手机浏览器只有在 **HTTPS 网址** 下才允许用麦克风，所以要把这个文件夹放到网上（免费）：

**最简单：Netlify Drop**
1. 电脑打开 https://app.netlify.com/drop
2. 把整个文件夹拖进去，得到一个 `https://xxx.netlify.app` 网址
3. 手机打开这个网址 → 浏览器菜单「添加到主屏幕」，就像 App 一样用

也可以用 GitHub Pages、Cloudflare Pages、Vercel。

## 第一次使用
1. 到 https://aistudio.google.com/apikey 申请 API Key
2. 打开 App →「设置」→ 粘贴 Key → 点「测试连接」
3. 模型默认 `gemini-3.6-flash`；想更快更省用 `gemini-3.5-flash-lite`

**国内网络**：手机需要开代理才能连上 Gemini；或在设置里的「API 地址」填自己搭的反向代理。

## 说明
- API Key 和练习记录只保存在你手机浏览器本地，不会上传到别处（除了发给 Gemini 分析）。
- 换手机前在「设置」里导出备份。
- 录音最长 60 秒；说不了的时候可以点「改用打字」。
- 文件：`index.html`（全部功能）、`sw.js`（离线缓存）、`manifest.webmanifest` 和图标（添加到主屏幕用）。
